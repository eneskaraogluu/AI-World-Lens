RESEARCH METHOD

How the lens works

01

Experiment protocol

  • Neutral occupation prompt
  • 10 independent generated samples
  • OpenAI GPT Image generation
  • Gemini Vision is the primary analyzer
  • OpenAI Vision fallback is always user-initiated
  • Validated generation + analysis pairs only
02

Interpretation limits

  • Labels reflect visual presentation, not verified identity.
  • Ten samples demonstrate the method; they do not estimate a population.
  • External models can produce nondeterministic results.
  • Deviation is descriptive and is never shown without validated classifications.
03

Data integrity

  • One active vision provider is used per final experiment.
  • UNVERIFIED means the image exists but analysis was unavailable.
  • FAILED means image generation itself did not complete.
  • Prepared replay creates no provider requests or new records.
